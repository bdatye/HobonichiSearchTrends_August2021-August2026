# HobonichiSearchTrends_August2021-August2026🖋️
This is a simple project analyzes google web search and Youtube search trends for Hobonichi from August 2021 to August 2026, focusing on worldwide searches and searches from US and Japan.

## What is Hobonichi?
Hobonichi is a popular stationery/planner company originating in Japan. It has a line of planners including: Hobonichi Techo Original, Hobonichi Cousin, Hobonichi Weeks, etc. It is a very popular planner within the planner/bullet journaling community and I wanted to see how searches for it vary throughout the year.

## The Dataset
The data for this project comes from Google trends [https://trends.google.com/trends/](https://trends.google.com/trends/)
It includes data for August 2021 to August 2026 for the following searches:
-Worldwide web searches and Youtube searches for Hobonichi
-USA web searches and Youtube searches for Hobonichi
-Japan web searches and Youtube searches for Hobonichi
-Japan web searches and Youtube searches for ほぼ日 ("Hobonichi" in Japanese)
